# English Hoops: Reported Speech — direkte und indirekte Rede (Jahrgang 8)

Duell-Lernspiel für zwei Teams an einem iPad, nur zum Thema direkte und
indirekte Rede. Gegeben ist jeweils ein Satz in direkter Rede, gefüllt wird die
Lücke in der indirekten Rede. Jede richtige Antwort ist ein Korb.

**Spielen:** https://teachingeng.github.io/english-hoops-reported-speech/

## Inhalt

72 gepaarte Aufgaben (144 Sätze), sechs Themen zu je 12 Paaren:

- simple present → simple past
- simple past → past perfect
- present perfect → past perfect
- Progressive-Formen
- can und will → could und would
- Fälle ohne Backshift (past perfect, would, could)

## Technisches

- Eine einzige HTML-Datei (`index.html`), läuft nach dem Laden offline
- Keine externen Bibliotheken, Web-Fonts, Bilder, Sounds oder Tracker
- Keine Netzwerkanfragen, kein Speichern von Namen oder Ergebnissen
- Spielfeld, Spielfiguren und Animationen werden per Canvas aus Code gezeichnet

## Nutzung im Unterricht

Den Link auf dem iPad in Safari öffnen, Querformat empfohlen. Die Seite kann
zum Home-Bildschirm hinzugefügt werden.
