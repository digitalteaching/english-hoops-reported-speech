How to play

Each question shows a sentence in direct speech and the same sentence in reported speech with one gap. Pick the form that fits the gap.

Rules

A correct answer scores one basket. A wrong answer scores nothing — there is never a point off. After every answer the solution and the rule appear for a moment, then that team moves on. Both teams get the same question number at the same level of difficulty, but never the same sentence, so copying from the neighbour does not help. The four options appear in a different order on each side.

Controls

Pause freezes the clock for both teams. Leaving the app pauses the game automatically. Escape closes the pause box and this box; the setup and the final score stay open until you choose a button.

Data

This game collects no data at all. Nothing is saved, no names, no results, no cookies, no storage. Closing the tab clears everything.

Where everything comes from

All questions were written for this game and are not taken from any textbook. Every graphic is drawn in code on a canvas — no images, no icons, no stock material. The typeface is whatever standard sans-serif your device already provides; no font file is loaded. The game runs completely offline and calls no server.
